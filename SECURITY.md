# Security policy

## Supported versions

Only the latest published version gets security fixes.

## Report a vulnerability

Do not open a public issue for a security problem.

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Tell us the affected version, the impact, and the steps to reproduce.

Only the maintainers can read your report. Expect a first reply within 7 days.
When a fix is ready, we publish a new version and a GitHub security advisory.
