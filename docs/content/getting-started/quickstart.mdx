This page takes about two minutes. You need Node.js 22.12 or newer.

{/* kit:library */}

## From code

<Steps>
  <Step title="Install the package">

```package-install
npm install tsdown-kit
```

  </Step>
  <Step title="Make a slug">

```ts ts2js index.ts
import { slugify } from 'tsdown-kit'

console.log(slugify('My First Blog Post!')) // 'my-first-blog-post'
```

  </Step>
  <Step title="Change the output">
    Pass options as the second argument. Each one is optional.

```ts ts2js index.ts
slugify('My First Blog Post!', { separator: '_' }) // 'my_first_blog_post'
slugify('My First Blog Post!', { lowercase: false }) // 'My-First-Blog-Post'
slugify('My First Blog Post!', { maxLength: 8 }) // 'my-first'
```

  </Step>
</Steps>

{/* /kit:library */}
{/* kit:cli */}

## From the command line

<Steps>
  <Step title="Slugify an argument">

```sh
npx tsdown-kit "My First Blog Post!"
# my-first-blog-post
```

  </Step>
  <Step title="Slugify piped lines">
    Each line of input gives one line of output. Empty lines are skipped.

```sh
printf 'First post\nSecond Post\n' | npx tsdown-kit
# first-post
# second-post
```

  </Step>
  <Step title="Change the output">

```sh
npx tsdown-kit --separator _ --max-length 12 --keep-case "Hello Big World"
# Hello_Big_Wo
```

  </Step>
</Steps>
